# ADR-002: Demo as a Content Profile

**Status:** Accepted.

## Context

Prototype documents defined reduced mechanics, while the intended demo should resemble the final game and primarily limit content quantity.

## Decision

The demo uses the final core systems and a validated profile containing six classes, seven destinations, and six merchants.

## Consequences

Systems may not hardcode the demo counts. Features explicitly deferred in the demo scope remain the only mechanical exclusions.
