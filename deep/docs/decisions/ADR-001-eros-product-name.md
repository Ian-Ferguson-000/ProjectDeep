# ADR-001: Eros Product Name

**Status:** Accepted.

## Context

The newest loop draft used “Tavernbound,” while the project, save/export identity, and most current material use “Eros.”

## Decision

The canonical product name remains **Eros**. Tavernbound is an archived working-title reference only.

## Consequences

Canonical documents and player-facing text use Eros. Renaming project files, saves, or exports is unnecessary.
