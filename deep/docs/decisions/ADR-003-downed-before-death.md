# ADR-003: Downed Before Death

**Status:** Accepted.

## Context

The playable prototype immediately removed adventurers at zero HP. The broader loop requires rescue, injury, recovery, and less binary character storytelling.

## Decision

Zero HP creates Downed. Stabilization protects against the unresolved-death roll; settlement resolves injury or permanent death.

## Consequences

Combat, UI, AI, expedition outcomes, memorials, settlement, saves, and tests must migrate together. Immediate prototype permadeath remains documented only in the archive.
