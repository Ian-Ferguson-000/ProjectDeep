# Testing and Telemetry

**Purpose:** Define validation and balance evidence required for the demo.  
**Audience:** Engineering, QA, systems design, and production.  
**Owner:** QA/engineering.  
**Status:** Canonical requirements.

Automated coverage includes schema/reference validation, save round trips and migrations, deterministic generation, connected/completable floors, formula boundaries, transaction idempotency, outcome settlement, all class action slots in both modes, dungeon unlock graphs, and recovery safeguards.

Development telemetry records cycle/tier, candidates and assessment, resource sources/sinks, tabs, party/loadouts, rooms and damage, extraction depth/value, outcome reason, injury/death/recovery, relationships, and upgrade timing. Data is local and disabled in release unless explicitly approved. Balance simulations compare conservative, health-threshold, aggressive, low-spend, and high-spend policies.
