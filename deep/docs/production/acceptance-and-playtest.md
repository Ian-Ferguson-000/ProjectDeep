# Demo Acceptance and Playtest

**Purpose:** Define release evidence for the Eros demo.  
**Audience:** QA, production, design, and engineering.  
**Owner:** QA/production.  
**Status:** Active target.

A new player must complete the ownership tutorial, five full tavern cycles, at least one assessment/recruitment decision, a difficult Extract/Descend choice, a Downed stabilization, an unresolved injury/death settlement, a tab repayment, an equipment repair/assignment, a relationship event, a merchant/Favor unlock, and a tavern upgrade without developer explanation.

Automated acceptance must resolve exactly six demo classes, seven destinations, and six merchants from the demo profile; validate both modes for all destinations; round-trip all three save slots; migrate legacy aliases; reject duplicate settlement; and validate deterministic catalogs and floor generation.

Manual sweeps cover keyboard/controller input, UI scaling, audio and comfort settings, full/partial party outcomes, all dungeon hazards/bosses, recovery from no gold/no roster, and clean Windows export/boot.
